# Echo - The AI local music app


Echo is a modern music player project built with Swift and SwiftUI, designed with a strong focus on a clean, simple and modern user experience.

The goal of Echo is to provide a lightweight music player where users can manage their own music library, create playlists, organize songs and control playback through a familiar and polished interface. The project is designed around Apple’s modern UI principles and makes use of SwiftUI to create a responsive and native experience.

About the Project

Echo started as an experiment to see how far an entire application could be developed with the help of artificial intelligence.

This project was intentionally made using AI. The goal was not simply to use AI as an occasional coding assistant, but to explore what would happen if the development process — from the initial ideas and UI concepts to the implementation, debugging, improvements and documentation — was heavily driven by AI.

A large part of the code, architecture, features and problem-solving process was created with the assistance of AI. Human input was still used to define the direction of the project, test the application, make decisions about features and provide feedback, but AI played a central role throughout the development process.

This makes Echo partly an experiment: how capable can AI be when used as a primary development tool for a real application?

Features

Echo is designed to include features such as:

* Music library management
* Importing local audio files
* Song and artist information
* Play, pause, next and previous controls
* Automatic playback of the next song
* Playlists
* Playlist creation and management
* Playlist artwork
* Song search
* Song and artist editing
* Mini player
* Playback controls
* Dark mode
* Modern SwiftUI interface
* Native iOS design
* Smooth animations and transitions
* Persistent music library and playlist data

The project is continuously evolving, and some features may still be experimental or under development.

Built With

Echo is primarily built using:

* Swift
* SwiftUI
* AVFoundation
* MediaPlayer
* AVFAudio
* Apple’s native iOS frameworks

The project is intended to stay as close as possible to Apple’s native development ecosystem rather than relying on large third-party frameworks.

AI-Driven Development

One of the most important aspects of Echo is its development methodology.

Instead of following the traditional approach where a developer writes most of the code manually and occasionally uses AI for assistance, Echo was created with the intention of making AI a central part of the development process.

AI was used for things such as:

* Generating and modifying Swift code
* Designing parts of the application architecture
* Creating SwiftUI views
* Debugging compiler errors
* Finding solutions to implementation problems
* Suggesting improvements
* Implementing new features
* Refactoring existing code
* Explaining Apple’s frameworks and APIs
* Helping design the user interface
* Writing and improving documentation

The project therefore serves as an experiment in AI-assisted software development.

That does not mean that every decision was automatically made by AI. The development process still involved testing, experimentation, deciding what should be changed, finding bugs and determining what the application should ultimately become.

Why Make It This Way?

The main purpose of the project was to experiment.

AI-assisted programming is becoming increasingly capable, and Echo is an attempt to explore what happens when that technology is given a much larger role in the development of an application.

Instead of asking:

“Can AI write a piece of code?”

the idea behind Echo is closer to:

“Can AI help build an entire application?”

Echo is an ongoing attempt to answer that question.

Status

Echo is currently a work in progress.

The project is being developed incrementally, with new features, improvements and experiments being added over time. Some parts of the application may therefore be unfinished, experimental or subject to change.

Disclaimer

This project is primarily an experiment and learning project. It should not be considered a demonstration of perfect production-level software engineering.

Because AI was heavily involved in the development process, some parts of the code may be structured differently than they would be in a traditionally developed application. The project may also contain bugs, inefficient implementations or areas that could be improved.

That is part of the experiment.

Final Note

Echo was intentionally created to explore the possibilities of AI-first application development.

Almost every part of the project has been influenced by AI in some way, from writing code and solving problems to designing features and improving the application.

The project is therefore not only a music player — it is also an experiment into what modern AI-assisted development can achieve.

Built with Swift. Built with SwiftUI. Built with a lot of AI.
