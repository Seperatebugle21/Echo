Echo
Echo is an advanced, modern local music player for iOS, built natively using Swift and SwiftUI. The application is designed with an uncompromising focus on delivering a clean, intuitive, and high-performance audio experience that integrates seamlessly into Apple's native software ecosystem.

The primary objective of Echo is to empower users with a powerful platform to manage their local music collection, organize custom playlists, and stream audio through a refined, user-centric interface. With recent major architecture updates, Echo now features real-time synchronized lyrics, enhanced connectivity options, and expanded metadata capabilities.

Key Features
1. Comprehensive Library Management
Local Audio Import: Effortlessly import, organize, and manage local audio files within your library.

Metadata Editor: Directly modify song details, artist names, and album tags to maintain a clean and structured collection.

Instant Deep Search: High-performance search index across songs, artists, albums, and playlists.

Persistent Storage Engine: Robust local database management ensuring your library state, play counts, and custom arrangements are preserved.

2. Multi-Source Lyrics & Annotations Integration
Musixmatch Live Lyrics: Experience real-time, line-by-line synchronized lyrics that track audio playback with pinpoint precision.

Genius Knowledge Engine: Access rich background context, song annotations, and artist insights directly within the player interface.

Interactive Lyrics Progress: Tap any line in the synchronized lyrics view to instantly jump to that specific timestamp in the audio track.

3. Playback Controls & Connectivity
Miniplayer AirPlay Integration: Instantly route your audio output to external speakers, HomePods, or Apple TV using the dedicated AirPlay button embedded directly into the miniplayer.

Comprehensive Playback Engine: Full control suite including play, pause, track skipping, dynamic queue management, and automatic track transition algorithms.

Background Audio Processing: Optimized background execution providing uninterrupted listening while multitasking or with the screen locked.

4. Playlists & Customization
Playlist Architecture: Create, rename, reorder, and manage custom playlists on the fly.

Custom Cover Art: Upload custom artwork images to personalize your playlists and albums.

5. Ergonomic & Modern UI Framework
System-Wide UI Overhaul: A completely redesigned visual framework featuring dynamic color palettes that automatically adapt to the dominant colors of the active album art.

Refined Miniplayer & Full Screen Player: Re-architected interface layouts designed for maximum ergonomics and quick accessibility to core playback tools.

Native Ecosystem Adaptation: Full support for system-wide Light and Dark modes, complete with fluid SwiftUI transitions and native gestures.

Technical Specifications & Architecture
Target Operating System: Requires iOS 26.0 or higher.

Core Languages & Frameworks: Built 100% natively in Swift utilizing SwiftUI.

Audio Engineering: Powered by Apple's native AVFoundation, MediaPlayer, and AVFAudio frameworks for maximum resource efficiency and low power consumption.

Dependencies: Pure native architecture designed without relying on heavy third-party UI dependencies.

Project Status
Echo is an actively maintained software project undergoing continuous development, with regular updates focused on performance optimizations, refined playback mechanics, and enhanced user interface experiences.
